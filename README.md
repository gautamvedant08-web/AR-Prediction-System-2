# AR Prediction System

I'm working on an Accounts Receivable (AR) Prediction System as part of my Data Science internship project.

The project uses a B2B invoice and payments dataset containing 2 million records.

### What I've Done
- Cleaned and prepared the dataset using Python and Pandas.
- Checked missing values, duplicates, and invalid data.
- Performed Exploratory Data Analysis (EDA).
- Analyzed invoice amounts and payment patterns.
- Studied overdue and outstanding invoices.
- Performed invoice aging and correlation analysis.
- Created visualizations and identified useful business insights.

### Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.
